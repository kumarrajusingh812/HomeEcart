# HomeEcart वेबसाइट — शुरुआती डेमो

यह एक मोबाइल-फ्रेंडली, बिना build step वाला HTML/CSS/JavaScript डेमो है। इसे Vercel पर static website की तरह प्रकाशित किया जा सकता है।

## इस डेमो में क्या है?
- होमपेज और प्रोडक्ट कार्ड
- कैटेगरी और सर्च
- रिटेल तथा होलसेल के उदाहरण वाले रेट
- कार्ट में सामान जोड़ना/हटाना और कुल रकम
- नाम, फोन और पता वाला ऑर्डर फॉर्म
- WhatsApp पर ऑर्डर अनुरोध भेजना

## जरूरी बदलाव करने से पहले
1. `app.js` खोलें।
2. सबसे ऊपर `WHATSAPP_NUMBER` में अपना WhatsApp नंबर डालें। अंतरराष्ट्रीय प्रारूप में देश कोड सहित नंबर रखें, जैसे भारत के लिए `91XXXXXXXXXX` (प्लस चिह्न नहीं)।
3. `products` सूची में नमूना सामान और कीमतें अपनी असली जानकारी से बदलें।
4. कीमतें अभी सिर्फ उदाहरण हैं। होलसेल कीमतों को अपने हिसाब से जाँचें।

## मोबाइल से GitHub और Vercel पर प्रकाशित करना
1. GitHub.com पर अकाउंट बनाएँ/लॉग इन करें।
2. `New repository` चुनें, नाम रखें `homeecart-demo`, और `Create repository` दबाएँ।
3. `Add file` → `Upload files` चुनें और इस ZIP से निकली सभी फाइलें अपलोड करें: `index.html`, `style.css`, `app.js`, `vercel.json`, `README-HINDI.md`।
4. `Commit changes` दबाएँ।
5. Vercel.com पर GitHub से लॉग इन करें।
6. `Add New` → `Project` चुनें, `homeecart-demo` repository को `Import` करें।
7. Framework Preset में `Other` चुनें। Build Command और Output Directory खाली रखें; इस डेमो में build step नहीं है।
8. `Deploy` दबाएँ। सफल होने पर Vercel एक `*.vercel.app` लिंक देगा।

## इस डेमो की सीमाएँ
- ऑर्डर WhatsApp में संदेश के रूप में भेजा जाता है; डेटाबेस में अपने-आप सेव नहीं होता।
- लॉगिन, पासवर्ड, admin panel, वास्तविक स्टॉक, delivery tracking और online payments शामिल नहीं हैं।
- रिटेल/होलसेल स्विच अभी ब्राउज़र में दिखाई देने वाली कीमत बदलता है; ग्राहक की भूमिका सर्वर से सत्यापित नहीं होती।
- यह शुरुआत और सीखने के लिए है, पूर्ण व्यावसायिक स्टोर नहीं। लाइव व्यवसाय से पहले सुरक्षा, गोपनीयता, ऑर्डर रिकॉर्ड, भुगतान और Vercel की वर्तमान योजना/उपयोग शर्तें जाँचें।
